쉘 에서 파이선의 버전을 확인하기 위해서는

python -V

를 사용하면 된다.

하지만 실제 스크립트를 작성할때

os.system("python -V")

를 실행하게 되면 출력값이 변수에 저장되지 않는다.

import sys

한 뒤

sys.version_info

하게되면 값이 변수에 저장되며 인덱스별로 접근할 수 있어

버전 정보에 따른 코드 작성이 용이하다.
