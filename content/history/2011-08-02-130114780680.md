8월부터 이상하게 사용하던 Adobe 프로그램들이 막힌 것 같다.

조만간 대책이 나오겠지만 PDT에 적응을 해버릴까 하는 생각.

JRE를 설치 후에도 실행이 안된다면 환경변수 설정이 되지 않은 탓이다.

아래 절차를 따르면 됨.

(경로는 버전에 따라 달라질 수 있슴)

② JDK PATH 설정하기 (환경변수)

- 내 컴퓨터 - 속성 - 시스템 등록 정보 - 고급탭 - 환경변수 선택

Administrator에 대한 사용자 변수 목록에서 PATH가 있으면 편집. 없으면 새로 만들기.

이미 있는 PATH를 편집해서 추가하는 경우, 세미콜론으로 구분하여 추가

C:\Program Files\Java\jdk1.6.0_26\bin**;**

- 시작 - 실행 : cmd - "javac" 실행시 옵션들이 보이면 제대로 설정된 것.

기존에 쓰던 드림위버처럼 원격으로 파일 전송이 바로 가능하게끔 하는 것이 관건이다.

PDT를 설치하려니 64비트 버전이 이상하게 없어서

할 수 없이 그냥 클래식 설치.

JRE 7 버전을 설치 후 환경변수 설정.

이클립스 실행 후 플러그인에서 PDT를 설치.

RSE를 설치.

RSE에서 새로운 커넥션을 생성하고...

중요한 것.

SFTP를 사용하는 경우 SSL ONLY를 선택해야함.

음 테스트를 해보려고 원격에서 새 파일을 하나 생성했더니

기존에 존재하던 파일들이 다 날라갔다.

반드시 백업을 해놓고 작업을 할 것!!
