몇 시간을 개삽질 해서 결국 셋팅 완료.

일단 nginx, php5-fpm등은 그냥 apt-get으로 설치하면 되는데...

nginx site-available 안에 magento 라는 이름으로 설정된 서버 설정 파일을 보자

server {

listen 80;

root /var/www/magento;

index index.php index.html index.htm;

server_name magento.local;

set $php_log /var/www/magento/var/log/php_errors.log;

location / {

try_files $uri $uri/ @handler;

}

location /app/                  { deny all; }

location /includes/             { deny all; }

location /lib/                  { deny all; }

location /media/downloadable/   { deny all; }

location /pkginfo/              { deny all; }

location /report/config.xml     { deny all; }

location /var/                  { deny all; }

location /. { return 404; }

location @handler {

rewrite / /index.php;

}

location ~ .php/ {

rewrite ^(.*.php)/ $1 last;

}

location ~ \.php$ {

fastcgi_pass 127.0.0.1:9000;

fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;

fastcgi_param PHP_VALUE error_log=$php_log;

include fastcgi_params;

}

}

여기까지 설정하고 2가지 문제가 생긴다.

1. 우분투에  init.d 에 설정된 데몬을 실행하는데 버그가 좀 있는 것 같다.
ssh 설치시에도 같은 현상을 보이는데 unknown jobs라며 데몬 실행이 안된다... 이건 뭐 왠진 모르겠고 그냥 리부팅 하면 해결된다.

2. php5-fpm에서는 또 다른 오류가 있다.
/etc/php5/fpm/pool.d/www.conf 파일을 열어보면
listen = /var/run/php5-fpm.sock 요 부분을 위에서 설정한 nginx 서버 설정 내의 fastcgi_pass 값과 일치시켜줘야한다.

listen = 127.0.0.1:9000 으로 변경하고 리부팅 하면 시발 끝

휴.

안그럼 계속 fpm쪽에서 내는 502 gateway Error를 보게 될 것이다.
