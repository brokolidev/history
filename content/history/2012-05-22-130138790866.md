우선 설치는

http://pypi.python.org/pypi/setuptools

에 가서 알맞은 egg 파일이나

rpm 혹은 소스 파일을 직접 받아서 컴파일 해도 관계 없다.

각 버전에 맞는 egg 파일을

해당 버전의 Python 디렉토리에 다운로드 한 후

(보통은 /usr/local/Python-x.x.x )

sh xxxxxxx.egg

하면 자동으로 설치가 된다.

사용법은

easy_install 모듈명

하면 자기가 알아서 찾아서 설치해준당

근데 해당 버전의 폴더에서 찾아야 해당버전 라이브러리가 깔리는 것 같기도 하다...
