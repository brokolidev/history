Kismet을 설치하기 위해

리눅스를 설치했다.

리눅스는.. 배포판 6.0을 설치 한 후

전체 업뎃을 해서 6.2 Final.

Kismet 패키지를 받아서 ./configure를 실행했더니

configure: error: Neither uclibc uClibc++ or standard gcc stdc++ libraries found.

이런 에러가 뜬다.

그래서 uClibc++를 찾아봤다.

http://cxx.uclibc.org/download.html

여기서 패키지를 다운받은 후 압축을 풀고 INSTALL 파일을 읽어보니

1)  Find the location of the GNU libsupc++.a file on your computer.
It will likely be in a location like:
/usr/lib/gcc-lib/i686-pc-linux-gnu/3.3.4/libsupc++.a
Make a note of this file path

2)  Run 'make menuconfig' which will bring up a nifty ncurses-based
configuration dialog system.  This is similar to the Linux kernel
configuration system, and was ripped directly from uClibc.

3)  Configure to fit your system.  Defaults will be good enough for
now.

4)  Under 'Library Installation Options', put the path to libsupc++.a
in the appropriate location.

5)  Save your configuration

6)  Compile by typing 'make'

7)  Install the library by typing 'make install'

8)  If you want to use this library as a part of your working system
and you did not install the library to a directory in the library
search path, you can either add the installation directory to
the /etc/ld.so.conf file, or (preferred) make a symlink from
the libuClibc++.so symlink into a directory in your search path,
such as /usr/lib

9)  Compile applications using the wrapper script provided in the bin
directory of the install path.  If you run into problems, please
let me know.

10) Enjoy!

libsupc++.a

이 파일 경로를 기억해 두라고 한다.

find를 이용해서 파일을 검색하니 이 파일이 없다...
구글링을 통해 알아보니 libstdc++ 와 관련된 파일인 것 같다

yum으로 search를 해보니

compat-libstdc++-296.i686 : Compatibility 2.96-RH standard C++ libraries
compat-libstdc++-33.i686 : Compatibility standard C++ libraries
compat-libstdc++-33.x86_64 : Compatibility standard C++ libraries
libstdc++.i686 : GNU Standard C++ Library
libstdc++.x86_64 : GNU Standard C++ Library
libstdc++-devel.i686 : Header files and libraries for C++ development
libstdc++-devel.x86_64 : Header files and libraries for C++ development
libstdc++-docs.x86_64 : Documentation for the GNU standard C++ library

이런 파일들이 있다.
devel 버전을 설치해준다.

그리고 나니 경로가 생겼다.
/usr/lib/gcc/x86_64-redhat-linux/4.4.4/libsupc++.a
이제 make menuconfig
를 해보니 화면이 하나 뜬다.
(여기서 ncurses가 없다며 오류가 뜬다면
ncurses-devel을 설치해준다)

다른건 다 디폴트로 두고
'Library Installation Options' 에 들어가서 libsupc++.a 경로만 지정해주면 될 것 같다.

make를 날려보니

WRAPPER_INCLUDEDIR=-I../include ../bin/g++-uc  -Wall -Wno-trigraphs -pedantic   -ansi  -Os -fPIC -o algorithm.o -c algorithm.cpp
../bin/g++-uc: line 28: exec: g++: not found
make[1]: *** [algorithm.o] Error 127

이런 에러가 뜬다.

g++가 없다는 얘기 같은데 검색해서 설치해본다.

yum install gcc-c++

make.

이상없이 컴파일이 잘 된 것 같다.
make install 해주고

다시 kismet을 설치해보자.

./configure 실행하니 정상적으로 완료가 되었다.

마지막에 나오는 설정 화면은 혹시 모르니 저장해두자.
