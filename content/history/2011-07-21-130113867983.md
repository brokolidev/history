한번에 값을 주는 방법을 사용해야한다.

따로따로 주면 이상하게도 값이 안넘어간다.

**첫번째 선언 방법**

```javascript
var arr = {};
arr["first"] = 1;
arr["second"] = 2;
arr["three"] = 3;
```

**두번째 선언 방법**

```javascript
var arr = { "first": 1, "second": 2, "three": 3 };
```

중에 두번째 방법을 써야만 post 파라미터에서 배열을 그냥 던져줘도

해당 페이지에서 값을 받는다.
