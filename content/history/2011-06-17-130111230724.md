이 글은 지극히 개인적인 용도이다.

쿼리는 보기 시작한지도 얼마 안되었고 DB도 여러가지 볼때마다 헷갈리고 써도
쓸때만 찾았다가 또 잊어먹고 하다보니 좀 헛된 검색과 낭비를 좀 막아보고자 모은다.... 아직 초기라 틀린 부분도 많고 좀
목적이 계속된 정리작업이 필요할 것을 염두에 두고 있는 포스팅이기 때문에 다른 사람들이 참고하기엔 무리가 있다고 본다.
(틀린 점도 꽤 있을것도 같기 때문에..)

원래는 SLQ 표준안인 ANSI 쿼리문을 기준으로 모아보려고 했는데 막상 하려니까 ANSI쿼리 정보를 많이 구할수 없어서 일단 작성하고 더 정리해 나가기로 했다.

### 오라클 / MS SQL 쿼리 문법 정리

#### 1. 조회 (SELECT)
```sql
DESC 테이블명; -- 테이블 정의 보기

SELECT * FROM 테이블명 WHERE 필드 = '조건' AND 필드2 = '조건2';
SELECT 필드1, 필드2, 필드3 FROM 테이블명;
SELECT * FROM TAB; -- 존재하는 모든 테이블 보기
SELECT DISTINCT 필드1 FROM 테이블명; -- 중복제거하기
SELECT 필드1 FROM 테이블 WHERE 필드2 BETWEEN 00 AND 00; -- 00부터 00 사이
SELECT 필드1 FROM 테이블 WHERE 필드2 IN (00, 00); -- 00과 00 중에서
SELECT 필드1 FROM 테이블 WHERE 필드2 LIKE '%단어%';
SELECT 필드1 FROM 테이블 WHERE 필드2 IS NULL; -- or NOT IS NULL
```

#### 2. 수정 & 삽입 (UPDATE & INSERT)
```sql
UPDATE 테이블명 SET 필드 = '값', 필드2 = '값', 필드3 = '값' WHERE 필드 LIKE '조건';
INSERT INTO 테이블명(필드1, 필드2) VALUES ('값', '값');
```

비교연산자 : `>`, `>=`, `<`, `<=`, `=`, `<>` (not equal)

#### 3. 테이블 정의 & 시퀀스 (DDL)
```sql
DROP TABLE 테이블명;

CREATE TABLE 테이블명 (
    id varchar2(15) primary key,
    pass varchar(15) not null,
    no number(5)
);

-- 시퀀스 생성
CREATE SEQUENCE 시퀀스이름
    increment by 1
    start with 1
    nomaxvalue
    nocycle
    nocache;

-- 외래키 생성
ALTER TABLE 테이블명 ADD (FOREIGN KEY (필드) REFERENCES 테이블명2);

-- 컬럼 수정 / 추가 / 이름변경
ALTER TABLE 테이블명 MODIFY (필드 타입);
ALTER TABLE 테이블명 ADD (새컬럼 VARCHAR(10) NULL);
ALTER TABLE 테이블명 RENAME COLUMN 컬럼이름 TO 새이름;
ALTER TABLE 테이블명 DROP COLUMN 컬럼;
```

#### 4. 주요 함수 & 고급 쿼리
```sql
-- Null값 처리하기
SELECT isNULL(필드, '0') FROM 테이블;

-- 방금 인서트한 자동증가값 ID 가져오기 (현재 세션에서만 사용 가능)
SELECT @@IDENTITY;
SELECT IDENT_CURRENT('테이블명');
SELECT @@ROWCOUNT; -- 수행된 SQL문에 의해 영향받은 행의 수

-- 날짜 계산하기
SELECT * FROM 테이블명 WHERE DATEADD(DAY, CONVERT(INT, 컬럼명), 날짜컬럼) > getdate();

-- 테이블 / 컬럼 정보 보기
EXEC sp_help 테이블;
EXEC sp_columns 테이블;

-- 앨리어스 사용
SELECT 필드 AS A FROM 테이블;

-- 변수 선언 및 할당
DECLARE @변수명 자료형, @변수명2 자료형;
SET @변수명 = 값;
SELECT @변수명;

-- 일부분만 가져오기
SELECT TOP 5 컬럼 FROM 테이블;

-- 범위 정하기 & 패턴 매칭
SELECT 컬럼 FROM 테이블 WHERE 컬럼 BETWEEN 10 AND 20;
SELECT 컬럼 FROM 테이블 WHERE 컬럼 IN ('aaa', 'bbb', 'ccc');
SELECT 컬럼 FROM 테이블 WHERE 컬럼 LIKE '%제목%';
```

#### 5. 조인 & 집계 (JOIN, GROUP BY, UNION)
```sql
-- GROUP BY & HAVING
SELECT 컬럼1, sum(컬럼2) FROM 테이블 WHERE 조건 GROUP BY 컬럼1 HAVING sum(컬럼2) >= 30;

-- INNER & OUTER JOIN
SELECT 컬럼 FROM 테이블 INNER JOIN 테이블 ON 컬럼 = 컬럼;
SELECT 컬럼 FROM 테이블 LEFT OUTER JOIN 테이블 ON 컬럼 = 컬럼;

-- 하위 질의 (IN, EXISTS)
SELECT 컬럼 FROM 테이블 WHERE 컬럼2 IN (SELECT 컬럼2 FROM 테이블);
SELECT 컬럼1 FROM 테이블 WHERE EXISTS (SELECT * FROM 테이블 WHERE 조건);

-- UNION
SELECT 컬럼1, 컬럼2 FROM 테이블
UNION
SELECT 컬럼1, 컬럼2 FROM 테이블;

-- 삭제 & 수정
DELETE FROM 테이블명 WHERE 조건;
UPDATE 테이블 SET 컬럼 = 값 WHERE 조건;

-- 트랜잭션
BEGIN TRAN;
ROLLBACK;
COMMIT;
```

> **참고 팁**
> 1. SELECT에 웬만하면 `*` 는 사용하지 않는다.
> 2. WHERE 절에서 연산자의 왼쪽은 가공하지 않는다. 컬럼을 가공하면 색인(인덱스)을 사용할 수 없다.  
>    예: `WHERE 컬럼 * 3 < 10` 대신 `WHERE 컬럼 < 10 / 3` 을 사용하자.
