JSON에 관한 기초적인 내용들은 검색을 통해 쉽게 접할 수 있다.

하지만 막상 JSON을 어떻게 작성해서 어떤 식으로 이용을 해야 하는지

기초부터 기술해 놓은 웹 문서를 찾기가 어려웠다.

그래서 지난 며칠간 이해한 내용을 토대로 만들어본 JSON 예제를 올려본다.

(편의상 존칭 생략)

필요한 사전 지식 - jQuery, PHP, JSON, HTML

1. JSON 문서 만들기

대규모 웹 사이트에서 어떤 식으로 JSON 문서를 관리하는지는 알 수 없지만

(아마도 폴더를 따로 생성하여 관리하겠지)

개인 프로젝트등의 소규모 프로젝트는 굳이 따로 폴더를 생성하여 관리해줄 필요가 없으므로

그냥 일반적으로 자바스크립트 폴더에 함께 담아두는 것이 좋다.

새 문서를 생성하고 gallery.json.php  로 저장해준다.

확장자를 php로 해 준 이유는 db에서 정보를 받아오기 때문이다.

일단 쿼리를 받아온다.

<?php

header("Content-Type: application/json");

require_once( "../includes/connect.inc.php" );

$query = "SELECT * FROM gallery";

$result = mysql_query( $query ) or die( $query."<br />".mysql_error() );

?>

XML의 경우라면 이 결과를 mysql_fetch_assoc등의 함수로 루프문 안에 뿌려주겠지만

JSON의 경우 보다 간단하게 mysql_fetch_object 함수로 루프문을 통해 배열에 담아준 뒤

json_encode를 이용해 뿌려주면 된다.

<?php

header("Content-Type: application/json");

require_once( "../includes/connect.inc.php" );

$query = "SELECT * FROM gallery";

$result = mysql_query( $query ) or die( $query."<br />".mysql_error() );

$result_array = array(); // 결과 값을 담을 변수 생성

// 루프를 통해 배열에 오브젝트를 하나씩 담는다.

while( $row = mysql_fetch_object( $result ) ){

$result_array[] = $row;

};

// 결과값을 JSON 형식으로 변환한다.

$result_array = json_encode( $result_array );

echo $result_array;

?>

2. jQuery로 출력해보기.

이렇게 생성된 JSON 데이터를 jQuery를 이용해 간단하게 출력을 해보자.

root에 html 파일을 하나 생성한 후 json_test.html 로 저장해준다.

소스 코드는 아래와 같다.

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">

<html xmlns="http://www.w3.org/1999/xhtml">

<head>

<meta http-equiv="Content-Type" content="text/html; charset=utf-8" />

<title>JSON Test</title>

<script type="text/javascript" src="https://ajax.googleapis.com/ajax/libs/jquery/1.4.4/jquery.min.js"></script>

</head>

<body>

<div class="result"></div>

<script type="text/javascript">

$.getJSON("js/gallery.json.php",

function(data){

$('.result').html('<p>' + data[0].resized_url + '</p>');

});

</script>

</body>

</html>

기본적인 건 다 제외하고

가장 눈여겨 봐야할 것은 jQuery의 getJSON 메서드를 사용해서 JSON 데이터를 받아온 후

그렇게 받아온 데이터는 콜백 함수의 인자를 통해 접근 할 수 있다.

위 resized_url은 db의 썸네일 이미지 경로명이다.

받아서 변환 변환해서 사용하는 경우는 없겠지만 이해를 돕기 위해 만들어보았다.
