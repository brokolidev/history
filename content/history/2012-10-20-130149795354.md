기존에 CentOS가 버전이 6라 설치는 수월하다.

CentOS 가 5점대 버전일 경우 라이브러리등의 버전이 달라 애를 먹는 경우가 있다.

yum으로는 CentOS 5에서 6으로 버전 업데이트가 되지 않으니

맘 편하게 6으로 설치하는 것을 권장.

wget http://downloads.sourceforge.net/project/ntop/ntop/Stable/ntop-5.0.1.tar.gz?r=http%3A%2F%2Fsourceforge.net%2Fprojects%2Fntop%2Ffiles%2Fntop%2FStable%2F&ts=1350694501&use_mirror=jaist

위 ntop 미러 주소에서 받아서 압축을 푼다.

yum install subversion python python-devel -y

현재 시점에서는 python 2.6.6이 설치 된다.

ntop5는 python2.6 이상을 요구하므로 충족.

**파이선을 수동 설치시, 혹은 엔탑 컴파일시에 **

**libpython2.7.a 등의 라이브러리 에러가 나는 경우**

**prefix에 해당 파일을 복사해서 넣어준다.**

./autogen.sh

로 configure를 실행해본다.

make && make install 까지 에러가 안나면 성공.

에러나면... 기타 버전을 맞춘 뒤에 autoconf 하고 다시 autogen.sh를 실행한다.

아마 거의 python 버전이나 autoconf 버전 문제일 것이다.

make install 하기 전에 기존에 설치된 ntop은 해당 폴더에서 make uninstall 하여 삭제해준다.

끝!
