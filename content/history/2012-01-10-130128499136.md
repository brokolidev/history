지난 며칠간 이 문제 때문에 골머리를 조금 앓았다.

해당 문제는 ntop을 설치한 총 4대의 서버중에서 2대에서만 지속적으로 발생했으나 타 서버에서도 로그에 같은 에러 메시지가 남아있었다.

일단 segfault라는 오류는 검색 결과 메모리에 값을 잘못 덮어 씌울 시에 발생하는 에러로, 메모리 불량이나
하드의 배드섹터로 인해서도 발생하는 것이라는 정보.

그러나 ntop을 설치한 4대의 서버가 모두 메모리나 하드가 불량일 확률은 극히 미미하므로 일단 소스코드의 오류로 판단을 하고 에러 메시지를 더 자세히 살펴보았다.

kernel: ntop[23399]: segfault at 5a2c ip 0000003a146479e7 sp 00007f5d957f6cd0 error 4 in libc-2.12.so[3a14600000+197000]

저 libc-2.12.so 라는 shared object 에서 오류가 발생했다.

해당 라이브러리를 업데이트 하려고 알아보니

미친짓이라거나 차라리 OS를 업데이트하라는 등의 이야기만 나온다.

자 그래서 컴파일 과정에는 문제가 없었나 다시 한번 재설치를 진행하면서 차근차근 살펴보기로 하였다.

설치 과정을 자세히 살펴보니 소스 폴더의 aclocal.m4 파일에서 라이브러리 버전을 명시하는 부분이 어 mismatch 오류가 날 경우가 있는데 해당 부분을 설치되어있는 라이브러리 버전으로 직접 변경해준 후 autoconf - make 명령어로 설치를 하면 문제없이 컴파일이 진행된다.

모두 설치하고 보니 맨 마지막에 뭔가 의심스러운 메시지가 뜬다.

라이브러리 관련하여 오래된 라이브러리가 발견되었으니 삭제하라는 메시지.

make listlibclean - 삭제 할 라이브러리 파일의 목록을 보는 명령

make libclean - 해당 라이브러리 삭제

아래 명령을 실행시켜 라이브러리를 삭제해주자.

또 /usr/local/var/ntop 폴더에 보면 ntop의 설정들의 저장되어 있으므로

make install을 하기 전에 해당 폴더를 삭제하면 초기 셋팅으로 설치가 된다.

일단은 하루가 지난 현재까지는 잘 실행이 된다.

리눅스 시스템에 대한 이해가 부족하니 많은 삽질을 하게된다.

인생은 끊임없는 수양이니

모르면 배우는 수 밖에.
