보통 DB를 수동 설치하면 이런 경우가 발생하는데,

DB에서는 한글이 잘 보이는데 어플리케이션에서는 깨진다던지,

아얘 DB에서 raw 데이터가 깨져서 들어간다던지 하는 경우이다.

설치 후에 my.cnf 파일을 찾아 [mysqld] 구문을 찾은 뒤

```ini
[mysqld]
character-set-server = utf8
collation-server = utf8_unicode_ci
```

위 코드를 추가해주면 된다.

mysql Ver 15.1 Distrib 10.3.14-MariaDB, for debian-linux-gnu (x86_64) using readline 5.2

위 버전에서는 /etc/mysql/my.cnf 에서 수정하였더니 정상 동작 하였다.
