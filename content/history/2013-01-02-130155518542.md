먼저 자바 코드를 보자.

```java
public final static byte[] myIV = { 10, 20, 30, 40, 50, 60, 70, 80 };

public static String encrypt(String data) throws Exception {
    if (data == null || data.length() == 0)
        return "";

    try {
        byte[] desKeyData = "keystring".getBytes();
        Cipher c3des = Cipher.getInstance("DES/CBC/PKCS5Padding");
        SecretKeySpec myKey = new SecretKeySpec(desKeyData, "DES");
        IvParameterSpec ivspec = new IvParameterSpec(myIV);
        c3des.init(Cipher.ENCRYPT_MODE, myKey, ivspec);

        byte[] inputBytes1 = data.getBytes("UTF8");
        byte[] outputBytes1 = c3des.doFinal(inputBytes1);

        sun.misc.BASE64Encoder encoder = new sun.misc.BASE64Encoder();
        return encoder.encode(outputBytes1);
    } catch (Exception e) {
        throw new Exception("FAIL_ENCRYPT");
    }
}
```

암호화 방식은 DES를 사용중이고 CBC 모드로 암호화하며 PKCS5 길이로 패딩 값을 주는 것을 알 수 있다.

PHP에는 mcrypt 라는 암호화 관련 라이브러리가 있다.

그 중 mcrypt_decrypt가 복호화를 위한 함수이다. php.net을 참조하니 친절하게 인자값에 대한 설명이 나와있다. 항상 느끼는 거지만 정말 정리가 잘 되어있는 교과서 php.net.

```php
string mcrypt_decrypt(string $cipher, string $key, string $data, string $mode [, string $iv])
```

첫번째로 자바에서 짜여진 코드와 다른 점은 PHP 함수는 모든 인자값을 String Type으로 받는 다는 점이다.

자바는 왜 저렇게 만들어놨는지 모르겠지만...

암호화 키와 IV값을 모두 바이트 배열로 받도록 만들어놨다.

뭐 어쨋든 keystring이라는 키값의 String 값은 나와있으므로 그냥 그대로 갔다가 쓰면 된다.

중요한 것은 저 맨 위에 선언되어있는 myIV라는 바이트배열.

일단 IV값이 뭔지 알아보기 위해 위키피디아에서 검색.

이 바이트배열을 PHP에서는 String으로 받으므로 구글링으로 byte를 string으로 변환하는 간단한 함수를 짠다.

결론

위 로직은 PHP에서 아래와 같은 함수를 사용하면 복호화가 가능하다.

```php
function pkcs5_unpad($text) {
    $pad = ord($text{strlen($text) - 1});
    if ($pad > strlen($text)) return false;
    if (strspn($text, chr($pad), strlen($text) - $pad) != $pad) return false;
    return substr($text, 0, -1 * $pad);
}

function byteToString($bytes) {
    $string = "";
    foreach ($bytes as $chr) {
        $string .= chr($chr);
    }
    return $string;
}

function decryptID($str) {
    $ivArr = array(10, 20, 30, 40, 50, 60, 70, 80);
    $myIv = byteToString($ivArr);
    $key = "keystring";
    $str = base64_decode($str);
    $str = mcrypt_decrypt(MCRYPT_DES, $key, $str, MCRYPT_MODE_CBC, $myIv);
    return pkcs5_unpad($str);
}
```

암호화 복호화는 한번도 구현을 안해봤는데
