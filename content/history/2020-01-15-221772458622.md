migration은 table 자체에 대한 scheme을 변경하거나, 테이블을 추가, 삭제하는 등의 경우 사용한다.

별도로 생성된 DB 및 Table을 연동해서 사용하고자 하는 경우, Model만 생성해주면 된다.

```bash
php artisan make:model 모델명
```

모델명은 원하는대로 적어 준 뒤 모델 클래스 내에서 table을 설정해주면 된다.

```php
protected $table = '테이블명';
public $timestamps = false;
```

위에서 table명에 timestamps를 false로 지정한 것은 저게 없으면 기본적으로 created_at, updated_at을 참조하기 때문에 해당 부분을 참조하지 않도록 설정 한 것이다.

이후 fillable등 Laravel 방식대로 모델에 코드를 추가하여 작업하면 된다.

```php
protected $fillable = [
    'name', 'email', 'password',
];
```

찾아보니 자료가 별로 없는 것 같아 기록해둔다.
