1. VMware 설정

플로피 디스크와 사운드 카드는 귀찮으므로 제거.

CD롬에 ISO 이미지를 넣어준다. DVD도 상관없고 Live CD도 상관 없지만 LiveCD는 여러 장으로

나뉘어져 있으므로 중간중간에 교체해줘야 하는 번거로움이 존재.

설치한 컴퓨터가 사양이 그렇게 좋지 않아서 램을 512M, 하드는 20G로 잡아주었다.

VM웨어 6.0 이하 버전에서는 커스텀으로 설정한 후 CentOS가 없으므로

Redhat Linux로 설저한 후 설치를 진행.

2. CLI 부팅

설치가 끝나면 CLI 모드로 변경해 주기 위해 터미널을 열고 파일을 하나 수정한다.

vim /etc/inittab 에서 5번으로 되어있는 것을 3번으로 변경.

init 3 입력하면 CLI로 전환.

(붙여넣기를 위해서는 putty로 접속해서 설치해도 좋음)

3. 업데이트 실행

yum install pcre pcre-devel php php-common php-gd php-cli php-mysql flex bison mysql mysql-devel mysql-bench mysql-server php-pear.noarch phppear-DB.noarch php-pear-File.noarch kernel-devel libxml2-devel vimenhanced.i386 -y

설치가 완료되면

yum -y update

해서 기타 업데이트도 설치.

* gcc랑 gcc-c++도 설치해준다. (libnet, libdnet 설치시 오류나는 경우)

완료되면 reboot.

4. vmware Tool을 설치하면 호스트 OS와 게스트 OS간 Drag & Drop이 가능하니 설치.

화면 큰것보다 이게 좋다.ㅋㅋ

룰셋은 수시로 업데이트 되며 기부 회원이 아닐경우 30일이 지난 룰만을 다운받을 수 있다.

6. 자 이제 압축 풀고 컴파일, 인스톨 하는 과정이다.

libnet, libdnet, libpcap은 /usr/local에 압축 풀고

./configure && make && make install

해주면 완료.

cp /usr/local/lib/libpcap.a /usr/lib 파일을 하나 복사.

daq를 인스톨 할때 저 폴더에서 libpcap을 찾기 때문이다.

daq도 마찬가지로 인스톨.

nbtscan 폴더를 생성한 후 그 안에서 압축을 풀어야 한다.

그리고 make만 실행.

snort도 ./confifure && make && make install 로 설치.

기본 프로그램들은 이러면 다 깔렸다.

7. 스노트 셋팅

mkdir /etc/snort

mkdir /var/log/snort

/etc/snort 안에 다운받아둔 스노트 룰을 압축 해제 한다.

tar zxvf snortrules.tar.gz -C /etc/snort

cp etc/* /etc/snort

groupadd snort

useradd -g snort snort

chown snort:snort /var/log/snort

touch /var/log/snort/alert

chown snort:snort /var/log/snort/alert

chmod 600 /var/log/snort/alert

mkdir /usr/local/lib/snort_dynamicrules

cp /etc/snort/so_rules/precompiled/Centos버전/i386/스노트버전/*.so /usr/local/lib/snort_dynamicrules

cat /etc/snort/so_rules/*.rules >> /etc/snort/rules/so-rules.rules

8. snort.conf 수정하기

가장 중요한 스노트의 컨피그 파일이다.

룰을 적용하거나 disable 할 수 있고 barnyard2 등의 다른 라이브러리와 연동하기 위한

설정도 필요하다.

RULE_PATH 를 /etc/snort/rules로 변경.

SO_RULE_PATH 를 /etc/snort/so_rules 로 변경.

PREPROC_RULE_PATH 를 /etc/snort/preproc_rules 로 변경.

기본적으로 스노트가 설치된 /etc/snort 아래의 경로로 잡아준다.

reputation을 검색하여 preprocessor의 모든 기능을 주석처리한다.

이걸 쓰려면 블랙리스트, 화이트 리스트를 지정해야 한다나...

unified2 항목으로 이동하여 주석처리된 output 라인을 주석 해제 시킨다.

로그 파일 이름을 merged.log 에서 snort.log 로 변경해주고 limit 128 이외에는 삭제한다.

자 여기까지 왔으면 mysqld와 httpd가 실행이 되어있는지 확인하고 안되어있으면 서비스를

start 해준다.

(ntsysv에서 부팅시 자동 실행으로 설정해줘야함)

9. MySQL 설정

아래는 사용자를 생성하고 권한 설정한 후 DB를 생성하는 부분이다.

사용자와 패스워드는 임의로 지정해도 괜찮지만 잘 기억해두어야 한다.

mysql

SET PASSWORD FOR root@localhost=PASSWORD('password');

create database snort;

grant ALL PRIVILEGES on snort.* to snort@localhost with GRANT option;

SET PASSWORD FOR snort@localhost=PASSWORD('password');

exit

cd /usr/local/snort-2.9.1.2/schemas

mysql -p < create_mysql snort

다음은 테이블이 잘 생성이 되었는지 확인하는 과정이다.

mysql 에 접속한 후 show databases;

snort  데이터 베이스가 생성되었는지 확인.

use snort;

show tables;

16개의 테이블이 생성 되었는지 확인.

10. GUI 환경 구축

스노트는 기본적으로 CLI 환경에서 사용하도록 만들어졌다.

그렇지만 다양한 라이브러리와 연동을 해서 출력값을 Web에서 확인할 수 있다.

대표적으로 ACID, BASE, snortreport 등이 있는데 기능은 거의 비슷하니

특별한 경우가 아니면 BASE 하나만 사용을 해도 큰 무리가 없을 것으로 보인다.

일단 메뉴얼에는 snortreport가 나와있으니 이거 먼저 해보자.

/var/www/html 에 snortreport 압축을 풀어준다.

srconf.php 파일에서

$pass에 DB 패스워드로 변경

JPGRAPH_PATH 를 ../jpgraph/src/ 로 변경 (이건 아직 안깔았는데 이 경로에다 깔아야 함)

NMAP_PATH 를 /usr/bin/nmap -v 로 변경

NBTSACN_PATH 를 /usr/local/nbtscan/nbtscan 으로 변경

자 근데 중요한거.

메뉴얼에서는 이상하게 jpgraph를 설정하는 부분이 빠져있다.

이것도 웹 기반 라이브러리니까 그냥 경로만 정확한 곳에 압축만 풀어주면 된다.

/var/www/html/ 안에 압축만 풀어주자.

(물론 폴더명은 위에 설정한대로 맞춰줘야한다.)

이걸 안해주면 snortreport에서 그래프가 보이질 않는다.

11. Barnyard 셋팅

barnyard는 스노트의 출력 기능을 대신하는 기능을 가지고 있다.

스노트는 패킷을 분석하는데 조금 더 신경을 쓸 수 있게 되므로 좀 더 효율적인 운영이 가능하다.

그래서 snort.conf 파일에 들어있는 디비 관련 설정을 사용하지 않고

barnyard 에서 설정해서 사용하는 것이다.

barnyard도 압출 풀고 까는건 똑같지만 mysql이 들어가는게 다른 부분이다.

./configure --with-mysql && make && make install

저 빨간 부분을 빼먹으면 나중에 다시 깔아도 애러가 난다.. 조심 ㅠ.ㅠ

그리고 /usr/local/barnyard아래/etc/barnyard2.conf 를 /etc/snort 로 복사해준다.

/etc/snort/barnyard2.conf 파일에서

config hostname을 localhost로 수정

interface 가 eth0 인지 확인

이후 데이터베이스가 나올때까지 output 메소드를 모두 주석처리.

데이터베이스에 라인을 추가해준다.

output database: log, mysql, user=snort password=password dbname=snort host=localhost

자 이제 snort.conf 에 룰을 적용하고

barnyard2와 snort를 구동시켜서 DB에 잘 들어가는지 확인만 하면 끝이다.

barnyard2 구동시에는 waldo 파일이 필요한데

cp /dev/null /var/log/snort/barnyard2.waldo

mkdir /var/log/barnyard2

한 후 구동 명령

/usr/local/bin/barnyard2 -c /etc/snort/barnyard2.conf -d /var/log/snort -f snort.log -w /var/log/snort/barnyard2.waldo

으로 실행 시키면 된다.

barnyard2를 띄워놓고 snort를 실행시키면 db로 캡쳐된 패킷이 저장된다.

snort 구동 명령

snort -c /etc/snort/snort.conf -i eth0

후아. 드디어 완료.
