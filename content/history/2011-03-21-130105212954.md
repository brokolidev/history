jQuery 의 간편한 AJAX 기능중에 하나인 load() 메소드를 이용하면

페이지를 쉽게 불러들일 수 있지만 그 안에 있는 엘리먼트들을 컨트롤 하기 위해서는

부모 문서에 있는 jQuery click() 메소드로는 컨트롤이 안된다.

하지만,

click() 대신 live( 'click', function(){ } ); 을 사용해주면 간단하게 해결 :)

로드 될 문서에 script 태그를 포함 시키는 방법도 있긴 하지만

중복되서 실행될 가능성이 농후하고

그런 경우 에러가 나지 않기 때문에 반복해서 테스트 해봐야 성능 저하가 오므로

디버깅 하기도 쉽지 않다.

메인 스크립트 파일에서 컨트롤 해주는 방법이 역시 가장 효과적이고 관리하기도 편한 방법이다.
