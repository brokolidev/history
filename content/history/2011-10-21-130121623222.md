한글이 깨지는 경우가 발생하기 때문에 아래처럼 얼럿을 띄우기 전에 메타태그를 추가해준다.

```php
function moveAfterMsg($msg, $url) {
    echo "<meta http-equiv=\"Content-Type\" content=\"text/html; charset=utf-8\" />
    <script type=\"text/javascript\">
        alert(\"{$msg}\");
        location.replace(\"{$url}\");
    </script>";
}
```
