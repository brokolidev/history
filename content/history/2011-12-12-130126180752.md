**

다운로드 받아야 하는 패키지

1. ntop

2. RRDTool

먼저 RRDTool이 깔려있어야한다. 관련 패키지를 깔아준다.

```bash
yum install libpcap-devel libpcap cairo-devel libxml2-devel pango-devel pango libpng-devel freetype freetype-devel libart_lgpl-devel libtool gdbm-devel GeoIP GeoIP-devel -y
```

다운로드 받은 RRDTool을 압축해제 한 후:

```bash
export PKG_CONFIG_PATH=/usr/lib/pkgconfig/
./configure --prefix=/usr/local/rrdtool/
```

컨피겨를 위처럼 실행해줘야 나중에 ntop 설치시 오류가 나지 않는다.

```bash
make && make install
cd /usr/local/
ln -s rrdtool-1.3.1/ rrdtool
```

이러면 완료.

설치가 잘 되었는지 확인하는 방법은 rrdtool 폴더 안에 들어가면 examples 폴더가 있다. 거기서 `stripes.pl` 을 실행 후 `stripes.png` 파일이 잘 생성되면 완료.

참고 사이트 - http://www.cyberciti.biz/faq/howto-install-rrdtool-on-rhel-linux/

이제 ntop을 설치할 차례. ntop 압축을 풀고 해당 디렉토리 안에서:

```bash
./autogen.sh
make && make install
```

**[유저 셋팅]**

```bash
useradd -M -s /sbin/nologin -r ntop
chown ntop:root /usr/local/var/ntop/
chown ntop:ntop /usr/local/share/ntop/
ntop -A # 패스워드 설정
```

**[실행 명령]**

```bash
/usr/local/bin/ntop -d -L -u ntop -P /usr/local/var/ntop --skip-version-check --use-syslog=daemon
```

**[실행 명령] - 인터페이스가 여러개인 경우**

```bash
/usr/local/bin/ntop -i "eth0,eth1" -d -L -u ntop -P /usr/local/var/ntop --skip-version-check --use-syslog=daemon
```

참조 사이트 - http://www.cyberciti.biz/faq/howto-install-ntop-on-rhel-centos-fedora-linux/

`http://server-ip:3000/` 으로 접속하면 모니터링 할 수 있다.

**부팅시 띄우는 방법**

`/etc/rc.local` 에 아래 라인을 추가해준다:

```bash

```
