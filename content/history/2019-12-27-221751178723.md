일단 로컬에 라라벨을 설치한다.

깃허브에 repository를 생성한다.

로컬에서 git remote add [원격 repository 주소] 하여 추가한 뒤 push 해준다.

라라벨은 기본적으로 .gitignore 파일이 포함되어 있어서 쓰잘데기 없는 파일은 github로 안올라간다.

실서버는 원격 repository에서 pull을 받으므로 실서버에서 쓰잘데기 없는 파일은 안올라간다는 얘기.

원격 서버에서도 폴더 생성하고 마찬가지로 git init 한 다음 리모트 repository 추가하고 pull을 받아온다.

nginx 설정은 https://laravel.com/docs/6.x/deployment 여기를 참고했다. 페이지가 바뀔 수 있으므로 코드를 붙여넣어둔다.

**Deployment - Laravel - The PHP Framework For Web Artisans**

In this document, we'll cover some great starting points for making sure your Laravel application is deploy...

laravel.com

```nginx
server {
    listen 80;
    server_name example.com;
    root /example.com/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-XSS-Protection "1; mode=block";
    add_header X-Content-Type-Options "nosniff";

    index index.html index.htm index.php;

    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php7.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

경로만 실서버 root로 잘 설정해주면 된다.

.env.example 을 복사하여 .env 파일을 생성한 뒤 DB 정보를 적어주었다.

여기까지 하고 도메인을 치던 IP를 치던 해서 브라우저로 해당 서버로 접속해보면..  에러가 뜰 것이다. nginx access 로그를 살펴본다. autoload.php를 못찾는단다.

실서버 root에서 composer install 하여 의존성 패키지들을 설치해준다.

그러구 들어가면 UnexpectedValueException 에러가 뜬다.

퍼미션 문제이니 아래와 같이 조정해준다.

```bash
/path/to/laravel-project $ sudo chmod -R 775 storage bootstrap/cache
/path/to/laravel-project $ sudo chown -R www-data:www-data storage bootstrap/cache
```

다시 들어가보면 앱 키를 생성하란다.

실서버 root에서

```bash
php artisan key:generate
```

실행해주면 자동으로 .env에 키가 들어간다.

접속해보면 이상 없이 잘 실행된다.

별거 아닌데 laravel을 어떻게 쓰고 개발하는지에 대한 자료들만 많고 실제 laravel을 live 시키는 과정은 잘 없는 것 같아서 올려둔다. laravel forge등을 써서 deploy 할 수도 있지만 이 것은 유료이니.. 물론 얼마 안하니 실제 서비스 할 때는 forge등을 사용하는 것이 정신 건강에 좋겠다.

기존에 사용중이던 nginx 서버를 이용해서 laravel을 테스트 해보고 싶어서 한 번 해보았다.
