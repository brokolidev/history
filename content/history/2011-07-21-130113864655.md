배열이 좀 크다 싶으면

```javascript
function print_r(arr) {
    for (var i in arr) {
        document.write(" [" + i + "] => " + arr[i] + " <br/>");
    }
}
```

로 직접 뿌린다.

배열이 좀 작으면

```javascript
function print_r(arr) {
    var result = "";
    for (var i in arr) {
        result += " [" + i + "] => " + arr[i] + "\n";
    }
    alert(result);
}
```

그냥 얼럿창에 뿌려준다.
